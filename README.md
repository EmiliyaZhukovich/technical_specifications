# Анализ и моделирование бизнес-процессов и REST API

Этот репозиторий содержит выполненные задания по дисциплине, связанной с бизнес-анализом, моделированием процессов и проектированием API.

## Содержание проекта

### Задание 1: Моделирование бизнес-процесса в BPMN

**Описание:**
На основе текстового описания процесса выдачи IT-оборудования сотрудникам компании X построена BPMN-диаграмма «как есть».

**Файлы:**
- `diagram.bpmn` - BPMN-диаграмма.

### Задание 2: Формулировка требований к новой функциональности

**Описание:**
Разработаны требования к новой функции Личного кабинета продавца на маркетплейсе - «Публикация товара на витрине».

**Содержание:**
- User Story с критериями приёмки.
- Полный Use Case «Публикация нового товара на маркетплейсе» (основной сценарий, альтернативные и исключительные потоки).

**Файлы:**
- `task_2.md` - полный текст требований и User Story.
- `activity_diagram.puml` - диаграмма активности.

### Задание 3: Проектирование REST API и алгоритм обработки

**Описание:**
На основе интерфейса регистрации пользователя в приложении Book Store спроектирован REST API и детальный алгоритм обработки на бэкенде.

#### 3.1 Описание REST API
- Эндпоинт: `POST /api/v1/auth/register`
- Подробное описание запроса/ответа, кодов ошибок, примеров.
- OpenAPI (Swagger) спецификация в YAML.

#### 3.2 Алгоритм обработки на бэкенде
- Пошаговый алгоритм с проверками (валидация, reCAPTCHA, уникальность username, хэширование пароля и т.д.).
- Диаграмма активности (Activity Diagram) в PlantUML.

## Технологии и инструменты

- **BPMN моделирование**: bpmn.io
- **Диаграммы**: PlantUML
- **Документация**: Markdown
- **API спецификация**: OpenAPI 3.0 (YAML)
